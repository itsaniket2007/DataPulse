# DataPulse 📊

A continuously evolving business analytics project focused on transforming raw business data into meaningful insights.

## 🎯 Project Goal

DataPulse is my long-term data analytics learning project.

Instead of creating multiple disconnected projects, I am continuously improving one analytics project by adding new concepts, tools, analyses, and business insights as I learn them.
